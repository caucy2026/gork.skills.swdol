## A. 用户新理解（铁律）

1. **没有 GM**：只用现账号真实书档与装备库存，不学不给不改库。
2. **并行时钟**：走路有延迟，读条/CD 要算；**不许**用瞬移 SAFE 假装活下来。
3. **定身前贴 Boss = 死**：龙奔 `11098`（range 6000，hp%−200）、贴脸物理、龙啸 `11102`（AOE 2000）都会杀人。
4. **召唤 `10735` = 拽玩家**：点名把人拉到 Boss 脚边再秒，**不是**召唤小怪。
5. **先定身再抽灵**：纸 `6044=ABSENT_0` 锁死祭符 `10712/10821`；全库只有 **nana** 有 `10837`；无纸主抽是刺客 `11125`（LIVE ≈−19/hit）。
6. **无敌坦短触 → 立刻撤 SAFE**：控/抽远站；魔尽前只靠 **金刚护脉 `10628`** 等自保罩（**见招拆招：OPTIMAL 记「无 id」OPEN**），蓝抽干才近战。
7. **十套组合仿真全部「能退=N」**（`GATE_DOCUMENTED`）：纸门 + 无第二定身 + `11125` 抽速不够见 `HARD_GATE.md` / `TEN-COMBOS-SCORED.md`。
8. **圈规**：同时进龙啸圈 ≤4；奶永不进圈；禁十人叠 ≤2000；禁双坦同放 `10513`。

## C. 八职 · 技能特点 / 开团左右 / 神龙有没有用

### 1. 剑客
- **特点**：近战剑技爆发 + 少量控/自 buff（Special7）。关键例：`11117` 杳冥降势、`10203` 极光剑式、`10118` 雷霆光铧、`10852` 铁布杉、`11116` 剑疾驶还。
- **开团左右**：**魔尽前板凳**；定身窗不抢拉、不贴脸。站 SAFE；`current_mp` 门后再切入。
- **神龙**：编制测号 `sxsxzzz5` 为近战板凳。本盘 OPTIMAL **不进主轴**（禁近战贴脸）。书有则用途=魔尽后爆发；未编入 A 队上场。

### 2. 魔刀客
- **特点**：先叠形态（命中/防/攻/生命）再打刀技。关键例：`10504` 蛇迹难辨、`10506` 天怒难犯、`10516` 万魔噬魂、`10534` 灵力护盾、`10525` 霸绝天地、`10508` 百器王刀。
- **开团左右**：同剑客——**怪被拉稳且已定身后**才考虑近战；开怪瞬间禁冲脸。神龙默认 **魔尽后**。
- **神龙**：测号 `12345` 板凳。主轴 **不用**。有书=魔尽近战；无编入 A。

### 3. 武术家
- **特点**：嘲讽拉仇恨 + 减伤/铁布 + 踢技。关键：`10513` 嘲讽挑衅（range 400，hate 12000）、`10954` 嘲讽狂舞、`10852` 铁布杉、`11078` 力抗山河、`10536` 天露赋畀。
- **开团左右**：**最先短触**——嘲讽醒 Boss → **立刻走撤** SAFE/HOLD；禁久站 ≤6000。HP 危急前触发 F1 第二武术单方换嘲（禁双 `10513` 同放）。
- **神龙**：**有用（主坦）**。`jiuyue` 书 VERIFIED：`10513@31`/`10954@33`/`10852@30`/`10536@34`。B 换嘲 `helen3` s0 同套 CLOSED_YES。并行时钟下走撤慢 → 常被龙奔在定身前点死（COMBO-PARALLEL）。

### 4. 刺客
- **特点**：远程枪/暗器 + 隐匿/爆发。关键：`10703` 瞄准、`10848` 连环、`11125` 噬灵连射、`11279` 五段击杀、`10930` 惊骇术。
- **开团左右**：SAFE 待命；**定身窗**走入 ≈1350 放 **`11125` 辅抽**；解锁走回 SAFE。五段/近切仅魔尽后。禁未定身贴脸。
- **神龙**：**有用（无纸默认主抽路径）**。`A88888`：`11125@4` LIVE mpΔ≈−19；弹药 `6524` 门。纸回来后让位祭符主抽。

### 5. 药师
- **特点**：奶/甲/HOT/群疗/无敌/定身针/复活。关键例：`10856` 弱奶、`10884` 续命汤、`11133` 苍冥沛血、`10523`/`11135` 无敌族、`10859` 定影灵针、`10055` 浴火重生。
- **开团左右**：**全程 SAFE**；须走近目标 ≤1600 抬坦即撤；**永不进 ≤2000**；不叠圈堆奶。无敌/甲无原生书则**不发明、不用 GM 探针**。
- **神龙**：`helen1`/`helen2` **仅** `10856@15` VERIFIED_WEAK_HEAL；`invuln=ABSENT`。用途=弱奶保坦；无甲/HOT/天灵 → 短触风险靠控场窗，不靠无敌。

### 6. 修罗医师（巫医）
- **特点**：减速/毒/破防/增伤/护驾；**不是主奶**。关键：`10743`/`10862` 缠身、`10102` 降血化气、`10626` 溢散溃体、`11150` 巫蛊毒咒、护驾族。
- **开团左右**：定身后短进上减速+破防+DOT，放完即出；护驾给脆皮。远程位，不占嘲讽/定身位。
- **神龙**：`helen` flex VERIFIED_BREAK：`10102@35`/`10626@36`。可选圈内第 4 人；本盘十套表算未强制 APL。无书当 ABSENT 不上。

### 7. 阴阳师
- **特点**：定身控场 + 倒转放大器 + 四系法伤 + 罩身。关键：`10837` 鬼影定身（range 2500，mp60）、`10836` 瘫痪大地、`10987` 倒转阴阳、`10628` 金刚护脉、四系输出。
- **开团左右**：**主控**——从 SAFE/外圈**走路**进 ≈1450–2500 → **`10837` 先手** →（可倒转）→ 四系；禁移动打断倒转。金刚护脉 C2 自保（**不抗物理**，OPTIMAL）。圈内与坦/抽合计 ≤4。
- **神龙**：**核心有用**。全库 `10837` holders=1（**仅 nana@37**）；B 控 `GATED_NO_B_ROOT`。`10628@50` 书有。无第二控 → 控场 OOM 后永久停机（HARD_GATE）。

### 8. 祭符师
- **特点**：召宠线 + 睡控 + **符纸抽灵**。关键：宠召 `11336`/`10833`；抽灵 `10712`/`10821`/`10815`（需纸 **6044**）；`10806` 南柯一梦。
- **开团左右**：战前可召宠（宠可前、人远程）；**有纸**才进圈循环 `10712↔10821`；**6044=0 禁空放**，本座不进抽灵轴。制符另页不进开团主循环。
- **神龙**：`nana1`/`ariesfei` 书有 `10712/10821/10815`，但 **`paper6044=CLOSED_ABSENT_0`（全库 any=0）→ GATED**。有书无纸 = 上场不加抽蓝。十套去掉祭符位分数几乎不变。
