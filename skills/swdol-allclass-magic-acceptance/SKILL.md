# 全职业魔法验收

## 目标
技能相关**全链路**打通，不是孤立点技能：
1. **先**把单职测试跑稳、效率拉高；
2. **再**接推荐栏 + 自动挂机；
3. **再**验团战协同（谁给谁加什么 buff/debuff）。
PASS 必须有业务证据；禁只扫当前页或仅 REQ/TIMING。

## 推进顺序（强制）
| 阶段 | 做什么 | 关单门槛 |
|---|---|---|
| A 单职稳 | 分母冻全；按用法翻页测；站桩/尸体/坐标条件正确 | 该职已学会能测项有 RESOLVE 结论表 |
| B 提效 | GM 配齐、512M 缓存、CDP、先推荐栏后全书 | 单位时间 RESOLVE 数↑，假 FAIL↓ |
| C 推荐+挂机 | 一键推荐→按实战序烟测→`party_auto` 短样例 | 推荐栏可轮转且有结算 |
| D 团战协同 | 双号：奶/巫医给主C 上关键技，吃法号验状态 | 关键技在目标角色上 RESOLVE/状态位 |

未完成 A 不宣称 C/D 通过。

## 分母
权威：Object.dbf + magic-role-lookup + SKILL-DENOM + `LegacyQuickMagicRoleProfile.h`。
字段含：目标类、装具、tab、是否推荐表、**限制（站桩/尸体/坐标/宠）**、**团战角色（自/友/敌）**。
职业 1..8；巫医口语=**修罗医师（6）**。

## 目标类与限制
| 类 | 条件 | 验收 |
|---|---|---|
| enemy | 可伤靶；毛毛不计 HPΔ | RESOLVE（+HPΔ） |
| self / party 友方 | 空选或选队友 | RESOLVE/状态位（协同时在**吃法号**上读） |
| corpse / coords / pet / throwable | 备齐条件 | 见名 |
| stationary | 停步停导航 | 走动打断≠PASS |

## 实战推荐原则（阴阳模板）
自 buff（可走位）→ 定身 → **倒转阴阳（站桩不可移动）** → 四系攻魔。
栏位 priority ≠ 施放序；挂机/验收以施放序为准。

## 团战：为什么带药师 / 为什么带巫医

### 药师（5）——续航与救场
**为什么需要**：主C/坦克要人奶、加甲、抬血上限、群疗、战中拉人；没有药师团战续航断档。
**常给队友加的（推荐族，具体以已学最高 tier）**：
- 单体治疗（如猿骨蛇胶类）
- 物防甲（凄魂鬼甲/女娲战甲类）
- 气血上限 buff（阴阳龙合/沌古上汤类）
- 持续 HOT（续命汤）
- 群疗（植衣披/神恩广泽类）
- 复活（浴火重生/九天降灵等，**必须有尸体**）
- 另有定身/驱魔等可按局选
**怎么验**：药师号施放 → 在**被加的队友**读 RESOLVE/状态，不单看施法者 REQ。

### 巫医=修罗医师（6）——减益与护驾
**为什么喜欢**：把敌人变脆、变慢，给主C 创造输出窗；护驾保脆皮。不是主奶。
**常打在敌人/队友上的**：
- 减速/缠身（毒蛊缠身类）
- 持续毒/DOT（尸蛊毒、千蛊化魂类）
- 破防/降血化气、增伤溃体（让全队伤害吃饱）
- 降攻/降命中/降闪避诅咒
- 护驾（怨灵护驾/元神出窍类 → 保主C 或奶）
- 团队属性（气壮山河类）
**怎么验**：debuff 在**敌目标**状态；护驾在**被护角色**；挂机烟测勿强求修罗本人 HPΔ。

### 其它职在团里怎么配合（摘要）
| 职 | 团里要他做什么 | 吃谁的加持 |
|---|---|---|
| 剑客/魔刀 | 近战爆发 | 药师甲/奶；巫医破防增伤 |
| 武术 | 嘲讽拉怪 | 药师 HOT；巫医护驾可转坦克 |
| 刺客 | 点杀后排 | 药师应急奶；巫医控速 |
| 阴阳 | 定身→倒转→四系 | 药师续航；巫医破防 |
| 祭符 | 宠线输出 | 宠也可吃部分辅助；先维持宠 |

双号最小协同样例：药师→剑客加甲+HOT；修罗→可伤靶上破防+减速；剑客再输出——三方各记一条 RESOLVE。

## F. 神龙开团铁律与八职左右（2026-11-03 用户新理解）

### 铁律（无 GM / 真时钟）
1. **没有 GM**：只用现账号真实书档与装备库存。
2. **并行时钟**：走路有延迟，读条/CD 要算；**不许**瞬移 SAFE 假装保命。
3. **定身前贴 Boss = 死**：龙奔 `11098`、贴脸物理、龙啸 `11102`。
4. **召唤 `10735` = 拽玩家到 Boss 旁秒杀**，不是刷怪。
5. **先定身再抽灵**：纸 `6044=ABSENT_0` 锁死祭符 `10712/10821`；全库仅 nana 有 `10837`；无纸主抽刺客 `11125`（≈−19/hit）。
6. **无敌坦短触 → 立刻撤 SAFE**；控/抽远站；魔尽前靠自保罩，蓝抽干才近战。
7. 圈规：同时进龙啸圈 ≤4；奶永不进圈；禁十人叠 ≤2000；禁双坦同放 `10513`。
8. 表算硬门：全库无纸 + 无第二定身 + 抽速不足 → 魔尽不可达时标 `GATE_DOCUMENTED`，禁止编造 6044/战中回蓝。

### 开团总序
SAFE 自 buff → 武术 `10513` 短触嘲讽并**走撤** → 阴阳**走入** `10837` 定身 → 定身窗抽灵（有纸祭符 / 无纸 `11125`）→ 弱奶只抬坦即撤 → 魔尽后近战切入。
