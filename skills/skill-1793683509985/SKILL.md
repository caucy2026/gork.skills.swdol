# 神龙开团八职左右

权威展开见仓库/箱内 `CLASS-OPEN-RAID-ROLES.md`（与本技能同步）。数据只取后台 CLOSED 书档与 Object 定义。

## 用户新理解（铁律）
1. 没有 GM：只用现账号真实书档与装备。
2. 并行时钟：走路有延迟，读条/CD 要算；不许瞬移 SAFE 假装保命。
3. 定身前贴 Boss = 死（`11098` / 物理 / `11102`）。
4. 召唤 `10735` = 拽玩家到 Boss 旁秒杀，不是刷怪。
5. 先定身再抽灵；`6044=0` 锁死祭符抽灵；全库仅一人有 `10837`；无纸靠 `11125`。
6. 无敌坦短触→立刻撤 SAFE；控/抽远站；魔尽前自保，蓝尽才近战。
7. 圈规：龙啸圈 ≤4；奶永不进圈；禁叠 ≤2000；禁双嘲同放。
8. 硬门达不到魔尽时标 `GATE_DOCUMENTED`，禁止编造纸/回蓝。

## 开团总序
SAFE 自 buff → 武术 `10513` 短触嘲讽并走撤 → 阴阳走入 `10837` → 定身窗抽灵 → 弱奶抬坦即撤 → 魔尽后近战。

## 八职左右
- **剑客/魔刀**：魔尽前板凳。
- **武术**：主坦短触→走撤；第二武术换嘲备用。
- **刺客**：定身窗 `11125` 抽灵。
- **药师**：SAFE 弱奶；永不进圈。
- **修罗**：定身后短进破防/减速/护驾。
- **阴阳**：主控定身；无第二控则 OOM 停机。
- **祭符**：有纸才抽；无纸不上抽灵轴。
